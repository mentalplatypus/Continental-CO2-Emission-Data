# CO₂ Emissions by Continent, 1750–2020

**Live:** https://mentalplatypus.github.io/Continental-CO2-Emission-Data/

A stacked area chart of annual production-based CO₂ emissions for each continent, made with Python, pandas, matplotlib and seaborn.

Data: [Our World in Data CO₂ dataset](https://github.com/owid/co2-data)

Part of [David Wang's portfolio](https://mentalplatypus.github.io/).
